### About Me

안녕하세요! 저는 AI가 훌륭한 '모방가'를 넘어 진정한 '창조자'가 될 수 있는 방법에 대해 고민하는 연구자, [이름]입니다.

저의 핵심 연구는 **생성 모델의 창의적 외삽(Creative Extrapolation)** 능력을 향상시키는 것입니다. 저는 고차원 데이터가 놓여있는 저차원 '다양체(Manifold)'를 증강하는 방식으로 이 문제에 접근합니다. VAE로 구축한 잠재 공간(Latent Space)에서 데이터 사이의 '빈 공간'을 채워 확산 모델(Diffusion Model)을 학습시킴으로써, 모델이 학습 데이터에 없던 새로운 샘플을 생성하도록 유도합니다.
