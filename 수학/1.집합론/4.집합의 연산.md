## 합집합(Union) $\cup$
두 집합의 원소를 모두 더하는 연산.
$A \cup B = \set {x | x \in A \text{ or } x \in B}$
논리적 의미($OR$): $x$가 $A$에 있을 수도, $B$에 있을 수도, 두 집합에 동시에 속해있을 수도 있음.

## 교집합(Intersection) $\cap$
두 집합에 공통으로 들어있는 원소만 추출하는 연산.
$A \cap B = \set {x | x \in A \text{ and } x \in B}$
논리적 의미($AND$): $x$는 $A$의 조건도 만족하고, $B$의 조건도 만족해야 한다.
교집합은 교환 법칙이 성립한다.($A \cap B = B \cap A$)
만약 두 집합 내 원소들이 겹치는 게 하나도 없다면 두 집합을 서로소($Disjoint$)라고 정의함. 예를 들어 짝수와 홀수의 집합을 생각해볼 수 있겠다.
$A \cap B = \emptyset$(공집합)
확률에서 두 사건이 동시에 일어날 수 없음을 의미하며 배반 사건이라고 부름.

## 차집합(Difference) -, \
$A$에서 $B$에 해당하는 성분만 걸러내는 연산
$A - B = \set {x | x \in A \text{ and } x \notin B}$
단순 $A$에서 $B$를 뺀다기보다는, $A$내 $B$와 겹치는 부분($A \cap B$)을 도려낸다고 이해하는게 정확함.
$A - B = A \cap B^c$
만약 전체 집합 $A$가 $B$의 모든 원소를 포함한다면, (즉, $B$가 $A$의 부분 집합이라면) $A$와 $B$의 차집합이 $B$의 여집합이 됌.($A - B = B^c$)

## 여집합(Complement) $A^c$
집합 $A$의 여집합은 전체집합 $U$의 원소 중 $A$의 원소가 아닌 것들의 집합이다. 이는 나를 제외한 나머지 전부를 의미하며, 반드시 전체 집합($U$)이 전제되어야 함.
$A^c = \set {x \in U | x \notin A}$
논리적 의미($Not$): $x$는 $A$가 아니다.
성질:
- $(A^c)^c$ = A(부정의 부정은 긍정)
- $A \cup A^c = U$(나와 내가 아닌 것을 합치면 전체)
- $A \cap A^c = \emptyset$(나이면서 동시에 내가 아닐 수는 없음 -> 모순)
-  $S - A = A^c$
- $S^c = \emptyset$

## 대칭차 $\triangle$
집합 **A, B**의 대칭차는 $A$에 속하거나 $B$에 속하지만, 동시에 둘 다 속하지는 않는 원소의 집합이다. 대칭차를 나타내는 기호는 $A \triangle B$ 이다.
![[Pasted image 20251221203354.png]]
대칭차를 수식으로 표현할 때 두 가지 방법으로 나뉜다.
배타적 관점(차집합의 합). $A \triangle B = (A - B) \cup (B - A)$: A의 고유 특성과 B의 고유 특성의 합.
전체적 관점(합집합에서 교집합 제거). $A \triangle B = (A \cup B) - (A \cap B)$: 전체 데이터 중 중복된 데이터를 소거.
이는 둘 중 하나만 만족할 때 참이라는 의미임. $XOR$문제를 생각해보자.

### 배타적 논리합
수리 논리학에서 2개의 명제 가운데 1개만 참일 경우를 판단하는 논리 연산이다. 약칭으로 $XOR, EOR, EXOR$라고도 쓴다.
$XOR$문제는 $A$ 또는 $B$중 하나만 참이어야 참이다.

| **x∈A** | **x∈B** | **A∪B (OR)** | **A∩B (AND)** | **A△B (XOR)**      |
| ------- | ------- | ------------ | ------------- | ------------------ |
| 0       | 0       | 0            | 0             | **0** (둘 다 없음)     |
| 1       | 0       | 1            | 0             | **1** (A만 있음)      |
| 0       | 1       | 1            | 0             | **1** (B만 있음)      |
| 1       | 1       | 1            | 1             | **0** (둘 다 있어서 탈락) |
대칭차는 아래 연산들이 성립함.
교환 법칙이 성립: 
$$A \triangle B = B \triangle A$$
결합 법칙이 성립:
$$(A \triangle B) \triangle C = A \triangle (B \triangle C)$$
항등원이 존재:
$$A \triangle \emptyset = A$$
역원이 존재:
$$A \triangle A = \emptyset$$

이 대칭차의 성질을 이용하여 암호화 알고리즘을 만들 수 있음. 평문 데이터를 $M$, 비밀 키를 $K$라고 할때, $M$에 $K$를 $XOR$하여 암호문 $C$를 만듦.
$$C = M \triangle K$$
반은 암호문 $C$에 다시 $K$를 $XOR$함.
$$C \triangle K = (M \triangle K) \triangle K$$
$$= M \triangle (K \triangle K)$$
$$= M \triangle \emptyset$$
$$= M$$
이 과정으로 원래의 평문을 복구할 수 있다.

## 연산 법칙
### 분배 법칙
$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
곱셉이 덧셈에 대해 분배되듯($a(b+c) = ab + ac$), 교집합은 합집합에 대해 분배됨.(역도 성립)
![[tempFileForShare_20251221-234300.jpg]]

### 드모르간의 법칙
수리 논리학, 집합론, 컴퓨터 과학 등에서 논리곱, 논리합, 부정, 연산 간의 관계를 기술하여 정리한 것이다.
$(A \cup B)^c = A^c \cap B^c$
우변: ($A$ or $B$가 아니다)  $A$도 아니고 $B$도 아니어야 한다.
좌변: $A$가 아니다 그리고 $B$가 아니다.

$(A \cap B)^c = A^c \cup B^c$
전체를 부정($^c$)하면, 각각을 부정하고 연산 기호도 뒤집힘.($\cup$ <-> $\cap$)
