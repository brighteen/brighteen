Disjoint Sets
공통 원소가 없는 두 집합. 두 집합 $A, B$가 $A\cap B = \emptyset$을 만족하면, 서로소 집합이라고 함.
논리적 의미:
$$\forall x, (x \in A \implies x \notin B)$$
모든 $x$에 대해 $x$가 $A$의 원소라면, $x$는 절대 $B$의 원소가 아니다.
이 논리가 상호 배타적(Mutually Exclusive)관계의 수학적 정의임.


셋 이상 집합에서의 서로소일땐 단순 $A \cap B \cap C = \emptyset$이 아닌, 서로 다른 두 집합이 모두 서로소여야 함.
$A \cap B = \emptyset$
$B \cap C = \emptyset$
$C \cap A = \emptyset$
왜 $A \cap B \cap C = \emptyset$만으로 서로소 할 수 없는가에 대한 예시는 다음과 같다.
- $A = \{1, 2\}$
- $B = \{2, 3\}$
- $C = \{3, 1\}$
이때 $A \cap B \cap C = \emptyset$를 만족하지만 $A \cap B = \set{2} \ne \emptyset$임. 따라서 이 집합들은 서로소 집합이 아니다.

Multi-Class Classification task를 보자. 임의의 입력 데이터 $x \in X$는 클래스 $C$중 오직 하나의 클래스에만 속해야 한다. 각 클래스를 $c_i$라고 하고, 각 클래스 $c_i$에 속하는 데이터들의 집합을 $S_i$라고 할 때, $$S_i = \set{x \in X \mid \text{label}(x) = c_i}$$이때 임의의 두 클래스 $i, j(i \ne j)$에 대하여 $S_i \cap S_J = \emptyset$이다.
만약 두 클래스 사이 교집합이 존재한다면 특정 데이터 $x$는 $c_i$면서 동시에 $c_j$라는 뜻이 되므로, 이는 다중 클래스 분류가 아니게 된다.
따라서 모든 클래스는 쌍마다 서로소(Pairwise Disjoint)이다.
구현적 관점에서 봤을 때, Softmax로서 모든 클래스 확률의 합이 1이 된다. 만약 특정 데이터 $x$가 '고양이'일 확률이 높아지려면 수학적으로 '강아지'일 확률이 낮아져야 한다.

Multi-Label Classification task에서는 클래스들이 서로소가 아니다. 하나의 데이터 $x$(이미지)에 여러 클래스(청바지, 파란색...)가 동시에 붙을 수 있다.
