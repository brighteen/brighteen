partition
주어진 집합의 원소들을 서로 겹치지 않는 부분 집합들로 남김 없이 분류하는 방법.

집합 $S$의 부분 집합들을 $P = {A_1, A_2, \dots, A_n}$이라고 할 때, 다음 두 가지 조건(수학적으로 엄밀하게는 3번째 조건까지 만족해야 함.)을 완벽하게 만족해야 $P$를 $S$의 분할이라고 부를 수 있음.

## 분할의 세 가지 조건
- 상호 배반
	- 나눠진 $A_n$끼리는 서로 겹치는 원소가 단 하나도 없어야 함.
	- $A_i \cap A_j = \emptyset$(단, $i \ne j$)
	- 어떤 원소 x가 $A_1$에 속한다면, 동시에 $A_2$에 속할 수 없음. 분류가 명확해야 함.
- 전체 포괄
	- 나눈 $A_n$를 다 합치면 원래 전체 집합 S가 되어야 함.
	- $\cup_{i=1}^n A_i = S$
	- 전체 집합의 어떤 원소라도, 나눠진 집합 중 어딘가 하나에는 반드시 속해야 함.
- 공집합이 아님(Non-empty)
	- $A_i \ne \emptyset$
	- 데이터 분석에서 데이터가 하나도 없는 클래스(또는 컬럼)는 필요없음.

ex. 전체 집합 S = {1,2,3,4,5}일때 부분 집합 A, B를 아래와 같이 정의할 수 있음.
A = {1,2}, B = {3,4,5}: 두 집합간에 중복이 없고, $A \cup B = S$를 만족함.
A = {1,2,3}, B = {3,4,5}: 두 집합간에 3이 겹치므로 분할이 아님.
A = {1,2}, B = {4,5}: {3}이 두 집합에 속하지 않았으므로 분할이 아님.

## 동치 관계
전체 집합을 분할했을 때, 같은 집합($A_i$) 내 들어있는 원소들끼리는 '같은 성질을 가졌다'고 간주하는데, 이를 동치 관계라고 함.
ex. 정수 집합 $\mathbb{Z}$을 '3으로 나눈 나머지'를 기준으로 분할한다고 했을 때:
- $A_0 = \set{\dots, -3, 0, 3, 6, \dots}$(나머지 0)
- $A_1 = \set{\dots, -2, 1, 4, 7, \dots}$(나머지 1)
- $A_2 = \set{\dots, -1, 2, 5, 8, \dots}$(나머지 2)
위 3개의 집합은 서로소이며, $A_0 \cup A_1 \cup A_2 = \mathbb{Z}$를 만족함.(분할 성립)
1과 4는 숫자로선 다르지만, 집합 $A_1$내에선 동등한 원소로 취급됨.

단순 분류 모델은 입력 데이터가 진돗개든 치와와든 전부 개라는 클래스를 부여함. 분류란, 복잡한 입력 공간을 유한한 동치류로 분할(분할되게하는 초평면을 찾는 문제)하는 과정이라고 볼 수 있음.

비지도학습의 클러스터링과 유사. 데이터를 K개의 클러스터로 분할하고, '같은 클러스터 안에 있는 데이터들은 같은(비슷한) 특성을 가졌을 것이다'라고 보는 것임.

## 분류 task에서의 분할
전체집합 $S$를 MNIST로 정의한다면$S$는 다음과 같이 정의할 수 있음.
$$S = \cup_{i=0}^9 A_i$$ $$S - \cup_{i=0}^9 A_i = \emptyset$$
![[tempFileForShare_20251222-002834.jpg]]
(엄밀히 따지자면 전체집합 S는 각 클래스 집합들의 합과 같아야 함.)
이때 각 클래스(집합)들이 배반이며($A_1 \cap A_2 = \emptyset$), 특정 데이터 $x$가 $x \in A_1$라면 $x \notin A_i, (i \ne 1)$임. 특정 데이터가 1이면서 동시에 2일 수 없다는 것이다.
이때 구현관점에서는 Softmax를 사용하여 확률이 가장 높은 클래스를 선택하며, 각 클래스들이 배반이라는 의미는, 모든 확률의 합이 1이 되는 것과 동일한 맥락임.

만약 클래스들이 배반이 아닌 경우(교집합 존재)
$$C_{dog} \cap C_{cat} \ne \emptyset$$
특정 데이터(이미지)$x$에 강아지와 고양이가 함께 있는 사진이 존재함. 이는 다중 레이블 분류 문제를 의미.
이때는 출력층의 활성화 함수를 Sigmoid를 사용하여 각 클래스별로 독립적으로 판단함.

## 배반과 확률의 총합이 1인 것은 어떤 관계를 가지는가?
배반은 확률의 총합이 1이 되기 위한 필요조건임.
두 사건 A, B가 배반이라고 가정했을때, 두 사건이 일어날 확률을 더할 수 있고, $P(A \cup B) = P(A) + P(B)$를 구할 때 중복되는 부분이 없음. 하지만 아직 두 사건일 발생할 확률의 합이 1이라는 보장은 없음.
두 사건을 주사위를 던지는 상황에서 각각 A = 1, B = 2라고 했을 때, 두 사건은 배반이지만, $P(A) + P(B) = \frac{1}{6} + \frac{1}{6} = \frac{1}{3}$임. 이때 분할의 성질중에 '전체 포괄' 조건이 추가되어야 함.
같은 맥락으로(A, B를 정의하듯이) 각 사건을 정의한다면 $P(A \cup B \cup \dots) = P(A) + P(B) + \dots$(확률을 쪼개서 더할 수 있음)
전체 포괄이므로 $A \cup B \cup \dots = S$를 만족함.
$P(A) + P(B) + \dots = P(S) = 1$

softmax: 클래스들이 분할 관계라고 가정함.(배반과 포괄을 만족) -> 확률의 총합이 1이 되도록 강제.
sigmoid(Multy-label): 클래스들이 독립적인 사건들임.(배반 X, 포괄 X) -> 확률 총합이 1이 될 이유가 없음.

## task가 생성이라면?
분류 모델에서는 각 클래스를 나누는 초평면을 찾는 것이었음. 그 초평면을 넘는 순간 클래스가 바뀌며 배반이라는 논리를 생각할 수 있었음.

task가 생성으로 넘어오는 순간, 생성모델의 목표는 초평면을 찾는 것이 아닌 잠재 공간에서 데이터 공간으로 변환하는 매핑 함수를 배우는 것임. 이때 각 클래스 사이에 무한한 교집합(연속성)을 만들어냄. 더 이상 완전한 배반이 아니게 된것임.

집합론의 관점에서 보자. 가령, $\mathbb{R}^{784}$ 내 MNIST데이터셋을 떠올린다면 이 $\mathbb{R}^{784}$내 실제 데이터 집합(manifold) $\mathbb{M}$은 $\mathbb{R}^{784}$의 부분집합 $\mathbb{M} \subset \mathbb{R}^{784}$임.
이때 부분집합(단순 포함 관계)과 부분공간(0벡터 포함유무, 벡터합과 스칼라곱에 대해 닫힌 형태를 갖는 특별한 부분집합)을 구분하여 생각해야 함.
