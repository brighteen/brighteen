수학에서 급수는 수열의 모든 항을 더한 것, 즉 수열의 합이다. 항의 개수에 따라 유한급수와 무한급수로 분류된다. 또, 무한급수는 수렴급수와 발산급수로 분류된다. 무한급수에 대한 깊이있는 분석은 해석학적 수단, 특히 극한의 개념을 필요로 한다.

수열 $(a_n)_{n=0}^{\infty}$에 대한 (무한) 급수 $\sum_{n=0}^{\infty}a_n$는 수열의 항들의 형식적인 합이다. 즉, $\sum_{n=0}^{\infty}a_n = a_0 + a_1 + a_2 + \dots$
위 급수의 부분합 $\sum_{n=0}^{N}a_n$은 처음 오는 유한 개의 항에 대한 합이다. 즉, $\sum_{n=0}^{N}a_n = a_0 + a_1 + a_2 + \dots + a_N$
수렴급수$\sum_{n=0}^{\infty}a_n$의 합은 그 부분합의 극한이며, 이 역시 $\sum_{n=0}^{\infty}a_n$로 표기한다. 즉, $\sum_{n=0}^{\infty}a_n = \lim_{N \to \infty}\sum_{n=0}^{N}a_n$

## 성질
합에 대한 성질을 나타내는 다음과 같은 항등식들이 성립한다.
- 점화식: 수열에서 이웃하는 두개의 항 사이에 성립하는 관계를 나타낸 식.
$$\sum_{k=1}^{n}a_k = \sum_{k=1}^{m}a_k + \sum_{k=m+1}^{n} a_k$$
- 덧셈의 보존
$$\sum_{k=1}^{n} (a_k+b_k) = \sum_{k=1}^{n}a_k + \sum_{k=1}^{n} b_k$$
- 분배 법칙
$$\sum_{k=1}^{n} c \cdot a_k = c \sum_{k=1}^{n} a_k$$
- 선형성: 이는 덧셈의 보존 및 분배 법칙의 일반화이다.
$$\sum_{k=1}^{n} (c \cdot a_k + d \cdot b_k) = c \sum_{k=1}^{n} a_k + d\sum_{k=1}^{n} b_k$$

기댓값이 $E[X+Y] = E[X] + E[Y]$의 형태로 분리되는 이유도 시그마가 선형이기 때문임.
>Q.시그마가 왜 선형 연산자인가?
>수학에서 어떤 함수나 기호가 선형성을 가지는지 확인하려면 가산성과 동차성을 만족해야 함.
>가산성(덧셈의 보존): 두 수열을 더해서 합을 구하나, 각각 합을 구해서 더하나 똑같음.
$$\sum_{k=1}^{n} (a_k+b_k) = \sum_{k=1}^{n}a_k + \sum_{k=1}^{n} b_k$$
$$(a_1 + b_1) + (a_2 + b_2) = (a_1 + a_2) + (b_1 + b_2)$$
동차성(스칼라 곱의 보존)
$$\sum_{k=1}^{n} c \cdot a_k = c \sum_{k=1}^{n} a_k$$
$$cx_1 + cx_2 + ... + cx_n = c(x_1 + x_2 + ... + x_n)$$
만약 발산하는 무한급수인 경우에는 복잡한 정리가 필요. 어떤 급수가 수렴할 때만 선형성을 만족함. 딥러닝에서 Loss가 무한대로 발산하면 어차피 학습이 실패한 것이므로, 'Loss가 수렴한다(유한하다)'고 가정하고 이 선형성을 사용함.

미분($\frac{d}{dx}$): 합의 미분은 미분의 합임. 즉, 개별적으로 미분해서 나중에 더해도 된다는 뜻임. 복잡한 신경망을 노드별로 미분하여 학습할 수 있는 이유임.
미분할 전체 손실 함수 L이 수많은 데이터의 손실 합($L = \sum L_i$)일때, 시그마가 선형이기 때문에 미분연산이 시그마 안으로 들어갈 수 있음.
$$\nabla \left( \sum L_i \right) = \sum (\nabla L_i)$$
>Q.미분 연산는 상수인가? 벡터 공간처럼 덧셈과 스칼라곱에 대해 닫혀있는가?
>상수가 아닌 함수(연산자)임. 하지만 시그마 관점에서 상수임. 시그마는 인덱스 i(또는 k)를 변화시키며 더하는 연산자이고 반면, 미분은 변수(x)에 대한 변화율을 봄. 미분 연산자 $\frac{d}{dx}$는 시그마의 제어 변수 i와 독립적이기 때문에 미분 연산자가 i에 영향을 받지 않는 상수로 취급됨.

>Q.미분 연산이 시그마 안으로 들어갔을 때 이점은?
>전체 데이터셋의 손실 함수를 $L_{total}$이라고 할 때
>$$L_{total} = \nabla\sum_{i=1}^{N} L_i(x) = \frac{d}{dx}(L_1+L_2+...+L_N)$$
>위 식은 모든 데이터에 대한 손실함수를 다 더해서 복잡한 함수를 만들고, 그것을 미분하라는 의미임. 이는 수학적으로 너무 복잡하고, 메모리에 한 번에 올릴 수도 없음.
>$$L_{total} = \sum_{i=1}^{N} \nabla L_i(x) = \frac{d}{dx}L_1+\frac{d}{dx}L_2+...+\frac{d}{dx}L_N$$
>각 데이터에 대한 손실함수를 따로 미분한 뒤에 나중에 그 기울기 숫자(gradient)들만 더하라는 꼴임. 이는 거대한 합성함수의 미분이 아닌, 작은 미분 N개로 쪼개짐. 따라서 동시에 여러 손실을 병렬 처리가 가능해짐.
>전체 데이터(N)에 대해 다 더하지 않고, 일부(batch size:M)만 더하므로서 M개만 기울기를 구하고 더한것이 전체(N) 기울기의 근사값이 됨. 이것이 SGD가 작동하는 원리임.
>

일부 특수한 합은 더 간단한 꼴의 식으로 나타낼 수 있다.
- 상수열의 유한합
$$\sum_{k=1}^n c = cn$$
- 등차수열의 유한합: 이를 삼각수라고 한다.
$$\sum_{k=1}^n k = \frac{n(n+1)}{2} = \frac{n^2}{2} + \frac{n}{2}$$

## 가중합(Weighted Sum)
입력 x와 가중치 w를 곱해서 더할 때 단순 $\sum$을 사용하면 루프를 n번 돌아야 함. 이때 $\sum$이 아닌 내적(dot product)을 통해 연산할 수 있음.
$$y = \mathbf{w}^T \mathbf{x}$$
```python
import torch

# 데이터 설정 (100만 차원)
w = torch.rand(1000000)
x = torch.rand(1000000)

# [방법 A] 시그마 (Loop)
# 엄청나게 느림
result = 0
for i in range(1000000):
    result += w[i] * x[i]

# [방법 B] 벡터 내적 (Vectorization)
# GPU 병렬 연산으로 순식간에 처리됨
result = torch.dot(w, x) 
# 또는
result = (w * x).sum()
```

데이터가 1차원 벡터가 아닌 2차원 행렬일 때는 급수가 두 개 필요함.
H x W크기의 이미지 픽셀 전체의 밝기 합 S를 구할 떄
$$S = \sum_{i=1}^{H} \sum_{j=1}^{W} x_{ij}$$
안쪽 시그마(j, 가로 방향)를 먼저 다 더하고, 그 결과들을 바깥쪽 시그마(i, 세로 방향)로 더함.

## Mean Squared Error
$$L = \frac{1}{N} \sum_{i=1}^{N} (y_i - \hat{y}_i)^2$$
i번째 정답 $y_i$와 예측값$\hat{y}_i$의 차이(에러)를 구해서 제곱함. 데이터 개수(N)만큼 모든 에러를 더한 후 정규화하면 하나의 스칼라장으로 표현됨
