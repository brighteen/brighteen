#math #linear_algebra
"$\mathbb{R}^3$의 벡터는 3개의 성분을 가진 3 x 1 열행렬이다. 이것은 3차원 좌표공간에서 점으로 표시할 수 있으며, 가끔 시각적으로 명확하게 표시하기 위해 원점에서의 화살표를 이용하기도 한다. 그림 6에 벡터 $\mathbf{a} = \begin{bmatrix} 2 \\ 3 \\ 4 \end{bmatrix}, 2\mathbf{a}$가 표시되어 있다."
3차원에서의 벡터 합과 곱은 2차원과 똑같은 연산 결과를 가진다.

$\mathbb{R}^n$의 벡터들
"$n$이 양의 정수이면, $\mathbb{R}^n$은 $n$개의 실수로 이루어진 모든 순서 있는 n짝의 집합을 나타낸다. 순서 있는 $n$짝은 다음과 같이 보통 $n \times 1$ 열행렬로 표시한다."
$$\mathbf{u} = \begin{bmatrix} u_1 \\ u_2 \\ \dots \\ u_n \end{bmatrix}$$
현재 실수 공간을 다루지만 복소수 공간에 대해서도 똑같은 성질들을 가진다. 차원이 0이거나 음수가 될 수 없다.

"모든 성분이 모두 영인 벡터를 영벡터라 하고 $\mathbf{0}$으로 표시한다($\mathbf{0}$의 성분의 개수는 보통 문맥상 자명하다)."
$\mathbb{R}^2$를 다루면 $\mathbf{0} = \begin{bmatrix} 0 \ 0 \end{bmatrix}$이고, $\mathbb{R}^5$를 다루면 $\mathbf{0} = \begin{bmatrix} 0 \ 0 \ 0 \ 0 \ 0 \end{bmatrix}$이다. 이를 매번 $\mathbf{0}_2, \mathbf{0}_5$라고 표기하기 않고, 문맥에 맞춰 알아서 해석한다.

"$\mathbb{R}^n$에 있는 벡터들의 상등과 스칼라배와 벡터합 연산은 $\mathbb{R}^2$에서와 마찬가지로 각각의 성분에 대해 정의된다. 벡터에 대한 이들 연산은 다음과 같은 성질을 가지며, 각 연산에 대응하는 실수의 성질에 의해 바로 증명된다. 이 절의 마지막 부분에 있는 복습문제 1과 연습문제 41, 42를 참고한다."
벡터의 성분이 실수이기 때문에, 실수가 가진 성질(덧셈 교환, 결합 등)들이 그대로 성립한다. 또한 2, 3차원의 직관들이 n차원에서 그대로 성립한다.

```
R^n의 대수적 성질
임의의 벡터들 u,v,w \in R^n과 임의의 스칼라 c,d에 대해 다음이 성립한다.
(i) u + v = v + u
(ii) (u + v) + w = u + (v + w)
(iii) u + 0 = 0 + u = u
(iv) u + (-u) = -u + u = 0, 여기서 -u는 (-1)u를 나타낸다.
(v) c(u + v) = cu + cv
(vi) (c + d)u = cu + du
(vii) c(du) = (cd)u
(viii) Iu = u
```
(i) 교환법칙 & (ii) 결합법칙: 계산 순서가 상관 없다.
(iii) 영벡터(0) & (iv) 역원(-u): '원점'과 '반대 방향'이 존재한다.
(v) ~ (viii) 분배법칙: 스칼라곱에 대한 분배법칙이 성립한다(선형성을 가진다).
(viii) 항등원: $1\mathbf{u} = \mathbf{u}$. 현재는 스칼라 1을 곱하지만 엄밀하게는 벡터 $\mathbf{u}$의 차원과 동일한 단위 행렬 $\mathbf{I}$을 의미한다.

>Q.왜 스칼라곱에 대한 분배법칙이 성립하면 선형성을 가지는가?
>[[선형성]]을 만족한다는 것은 구조를 보존한다는 뜻이다. 어떤 연산(현재 스칼라배)을 수행할 때, 스칼라곱 후 덧셈이나 덧셈 후 스칼라곱이나 두 결과가 같다면 그 연산은 가산성과 동차성을 모두 만족하므로 선형적이라고 한다. 

"간결하게 표기하기 위해 $\mathbf{u} + (-1)\mathbf{v}$와 같은 벡터는 $\mathbf{u}-\mathbf{v}$로 쓴다. 그림 7에 $\mathbf{u}-\mathbf{v}$가 $\mathbf{u}$와 $-\mathbf{v}$의 합으로 나타나 있다."
두 벡터의 뺄셈을 음수 스칼라곱을 취한 덧셈으로 해석하면 직관이 쉽다.
>$\mathbf{u} - \mathbf{v}$는 $\mathbf{v}$에서 $\mathbf{u}$로 가는 화살표와 같다. $\mathbf{u} - \mathbf{v}$를 $\mathbf{x}$라고 해보자. 우리는 이 $\mathbf{x}$를 구하고 싶다고 했을 때, $\mathbf{x} = \mathbf{u} - \mathbf{v}$이 식을 $\mathbf{v} + \mathbf{x} = \mathbf{u}$와 같이 바꿀 수 있다. 이를 기하학적으로 생각해보면 원점에서 $\mathbf{v}$만큼 간 후 $\mathbf{x}$큼 더 이동하여 $\mathbf{u}$에 도착한다. 즉, $\mathbf{u} - \mathbf{v}$의 결과 벡터가 $\mathbf{v} + \mathbf{x} = \mathbf{u}$를 만족하는 $\mathbf{x}$가 된다.
>이를 경사 하강법에 대입해보자. 현재 파라미터 $w_{t}$를 업데이트하기 위해 그래디언트 $\nabla L$를 사용한다(엄밀하게는 학습률 $\eta$를 곱한 $\eta\nabla L$이다). 이를 식으로 표현하면 $w_{t} = w_{t-1} - \nabla L$이다. 이를 약간 변형하면 $\nabla L = w_{t-1} + (- w_t)$로 표현할 수 있으며 이 변화량을 early stopping 조건으로도 사용한다.
>이를 기하학적으로 해석해보면 파라미터 공간에서 이전 파라미터 벡터에 $\nabla L$만큼 이동하여 새로운 파라미터를 얻는 과정으로 해석될 수 있으며, 이 $\nabla L$라는 것은 현재 파라미터 공간 안에 이전 파라미터에서 어느 방향으로 얼마나 이동해야 손실이 최적점(보통 최솟값)에 수렴하는지를 알려주는 방향벡터이다.
