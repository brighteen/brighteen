# 고윳값분해(Eigenvalue Decomposition)의 좋은 점과 유용한 성질 증명

---

## I. 고윳값분해의 좋은 점 (5가지)

### 1. 거듭제곱 계산 용이
- 어떤 \($n \times n$\) 정방행렬 \($A$\)가 대각화($diagonalizable$) 가능하다고 하자. 즉,
$$A = V \Lambda V^{-1}$$
  여기서 \($\Lambda$\)는 \($A$\)의 고윳값들을 대각원소로 갖는 대각행렬, \($V$\)는 그 고윳벡터들을 열벡터로 하는 정방행렬이다.

- 이때,
    $$A^k = (V \Lambda V^{-1})^k = V \Lambda^k V^{-1}.$$
  \($\Lambda$\)가 대각행렬이므로 \($\Lambda^k$\)는 대각원소(고윳값) 각각을 \($k$\)제곱하는 것으로 쉽게 계산 가능하다.

### 2. 역행렬 계산 용이
- 만약 \($A$\)가 가역이라면(\($\det(A) \neq 0$\), 즉 모든 고윳값 \($\lambda_i \neq 0$\)) 다음이 성립한다.
    $$A^{-1} = (V \Lambda V^{-1})^{-1} 
            = V \Lambda^{-1} V^{-1}.$$
- \($\Lambda$\)가 대각행렬이므로 \($\Lambda^{-1}$\)는 각 대각원소를 \($\frac{1}{\lambda_i}$\)로 만든 대각행렬이 된다.

### 3. 행렬식$\det(A)$ 계산 용이
- 행렬 \(A\)의 고윳값이 \($\lambda_1, \lambda_2, \dots, \lambda_n$\)이라면,
    $$\det(A) = \lambda_1 \lambda_2 \cdots \lambda_n.$$
- 대각화 가능하면 \($A = V \Lambda V^{-1}$\)이므로,
    $$\det(A) 
    = \det(V \Lambda V^{-1}) 
    = \det(\Lambda) 
    = \prod_{i=1}^n \lambda_i.$$

### 4. $\mathrm{tr}(A) = \sum \lambda_i$
- 대각화 가능하면,
    $$A = V \Lambda V^{-1} 
    \quad \Longrightarrow \quad
    \mathrm{tr}(A) 
    = \mathrm{tr}(V \Lambda V^{-1}) 
    = \mathrm{tr}(\Lambda) 
    = \sum_{i=1}^n \lambda_i.$$
- 일반적으로도(대각화 가능 여부와 무관하게) 행렬의 트레이스는 고윳값들의 합과 동일.

### 5. Rank 판정 (rank-deficient)
- 행렬 A의 고윳값 중 0이 있으면 $\det(A) = 0$이 되어 비가역(역행렬이 존재하지 않음)이 됨,
- 또한 0이 아닌 고윳값의 개수가 $\mathrm{rank}(A)$와 일치한다. 즉, 고윳값만으로도 $\mathrm{rank}$를 판단할 수 있음.

## II. 알아두면 유용한 점 (5가지)

### 1. \($A^T$\)의 고윳값은 \($A$\)의 고윳값과 같다
- **특성방정식식 이용**:
    $$\det(A - \lambda I) = 0 
    \quad \Longleftrightarrow \quad
    \det\bigl((A - \lambda I)^T\bigr) = 0 
    \quad \Longleftrightarrow \quad
    \det(A^T - \lambda I) = 0.$$
- 따라서 \($A$\)와 \($A^T$\)는 같은 특성다항식을 가지므로, 고윳값이 동일하다(대수적 중복도 포함).

### 2. \($A$\)가 직교행렬이면(\($A^T A = I$\)) \($\lambda_i = \pm 1$\)
- 직교행렬은 모든 벡터의 길이를 보존한다: \(\|Ax\| = \|x\|\).
- 만약 \($A x = \lambda x$\)인 고윳벡터 \($x \neq 0$\)가 존재한다면,
    $$\|Ax\|^2 = \|\lambda x\|^2 = |\lambda|^2 \|x\|^2$$
- 직교행렬의 정의상 \($\|Ax\|^2 = \|x\|^2$\). 따라서
    $$|\lambda|^2 \|x\|^2 = \|x\|^2 
    \quad \Longrightarrow \quad
    |\lambda|^2 = 1 
    \quad \Longrightarrow \quad
    |\lambda| = 1.$$
- **실수 직교행렬의 실수 고윳값**은 \($\pm 1$\)이 되며, 복소수로 확장하면 \($|\lambda| = 1$\)이 된다.

### 3. \(A\)가 PSD(Positive Semi Definite)이면 \($\lambda \ge 0$\)
- PSD 정의: 임의의 \($x \in \mathbb{R}^n$\)에 대해 \($x^T A x \ge 0$\).
- \($A v = \lambda v$\)인 고윳벡터 \($v \neq 0$\)에 대해,
    $$v^T A v = v^T (\lambda v) = \lambda (v^T v) = \lambda \|v\|^2.$$
- PSD 조건에 의해 \($v^T A v \ge 0$\)이고, \($\|v\|^2 > 0$\)이므로 \($\lambda \ge 0$\).

### 4. 대각화 가능할 때, 0이 아닌 고윳값의 수 = \($\mathrm{rank}(A)$\)
- \($A = V \Lambda V^{-1}$\)로 대각화 가능하다면, \($\Lambda$\)는 고윳값을 대각원소로 하는 대각행렬.
- \($\mathrm{rank}(\Lambda$)\)는 0이 아닌 대각원소(고윳값)의 개수와 같다.
- 유사변환(similarity transform)에 의해 \($\mathrm{rank}(A) = \mathrm{rank}(\Lambda)$\).  
  따라서 0이 아닌 고윳값의 개수 = \($\mathrm{rank}(A)$\).

### 5. 대칭행렬($symmetric matrix$)은 무조건 대각화 가능 (역은 성립 X)
- **스펙트럴 정리**: 실수 대칭행렬은 직교행렬로 대각화 가능하다.
    $$A = Q \Lambda Q^T 
    \quad (\text{여기서 } Q \text{는 직교행렬}).$$
- 이는 “고윳값이 모두 실수이고, 서로 다른 고윳값에 대응하는 고유벡터들은 서로 직교한다”는 성질을 통해 증명된다.
- 그러나 “대각화 가능 \($\implies$\) 항상 대칭”은 성립하지 않는다. 즉, 비대칭 행렬도 대각화 가능할 수 있다.

---

## 정리

1. **고윳값분해(EVD)의 장점**  
   - \(A^k\) 계산 용이  
   - 역행렬 계산 용이  
   - \(\det(A)\) 계산 용이  
   - \(\mathrm{tr}(A)\) 계산 용이  
   - 순위(rank) 및 가역성(0 고윳값 존재 여부) 판정이 쉬움

2. **알아두면 유용한 점**  
   - \(A^T\)와 \(A\)는 같은 고윳값을 가진다.  
   - 직교행렬의 실수 고윳값은 \(\pm 1\) (복소수 확장 시 \(|\lambda|=1\)).  
   - PSD 행렬은 모든 고윳값이 \(0\) 이상이다.  
   - 대각화 가능 행렬에서 0이 아닌 고윳값의 수 = \(\mathrm{rank}(A)\).  
   - 실수 대칭행렬은 항상 직교대각화 가능하며, 이는 일반 대각화 가능성과는 구별된다.
