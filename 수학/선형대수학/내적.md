두 벡터의 곱의 합이 어떻게 유사도를 의미하는가?

**1. 무대 설정 (삼각형 만들기)**

원점에서 시작하는 두 벡터 $\mathbf{u}$와 $\mathbf{v}$가 있다고 상상해 보세요.

- $\mathbf{u} = (u_1, u_2)$
    
- $\mathbf{v} = (v_1, v_2)$
    
- 두 벡터 사이의 각도 = $\theta$
    

이제 $\mathbf{v}$의 끝점에서 $\mathbf{u}$의 끝점을 잇는 벡터를 그리면 삼각형이 만들어집니다. 이 세 번째 변의 벡터는 $\mathbf{u} - \mathbf{v}$이다.

일반적인 삼각형에서 세 변의 길이($a, b, c$)와 사잇각($\theta$) 사이에는 다음과 같은 공식이 성립합니다(피타고라스 정리의 확장판이죠).

$$c^2 = a^2 + b^2 - 2ab \cos \theta$$

이것을 우리 벡터의 길이($\|\cdot\|$)로 바꿔서 써보겠습니다.

- $a = \|\mathbf{u}\|$
    
- $b = \|\mathbf{v}\|$
    
- $c = \|\mathbf{u} - \mathbf{v}\|$ (맞은편 변의 길이)
    

$$\|\mathbf{u} - \mathbf{v}\|^2 = \|\mathbf{u}\|^2 + \|\mathbf{v}\|^2 - 2\|\mathbf{u}\|\|\mathbf{v}\| \cos \theta \quad \cdots \text{(식 1)}$$

**3. 대수적 계산 (좌표 풀기)**

이제 기하학은 잠시 잊고, **좌표 계산(Algebra)**만으로 좌변의 $\|\mathbf{u} - \mathbf{v}\|^2$를 풀어헤쳐 봅시다.

- 벡터의 뺄셈: $\mathbf{u} - \mathbf{v} = (u_1 - v_1, u_2 - v_2)$
    
- 길이의 제곱(내적의 성질): 각 성분을 제곱해서 더함
    

$$\begin{aligned} \|\mathbf{u} - \mathbf{v}\|^2 &= (u_1 - v_1)^2 + (u_2 - v_2)^2 \\ &= (u_1^2 - 2u_1v_1 + v_1^2) + (u_2^2 - 2u_2v_2 + v_2^2) \end{aligned}$$

이제 짝을 맞춰서 정리합니다. ($u$는 $u$끼리, $v$는 $v$끼리)

$$\|\mathbf{u} - \mathbf{v}\|^2 = (u_1^2 + u_2^2) + (v_1^2 + v_2^2) - 2(u_1v_1 + u_2v_2)$$

여기서 $(u_1^2 + u_2^2)$는 $\|\mathbf{u}\|^2$이고, $(v_1^2 + v_2^2)$는 $\|\mathbf{v}\|^2$입니다.

$$\|\mathbf{u} - \mathbf{v}\|^2 = \|\mathbf{u}\|^2 + \|\mathbf{v}\|^2 - 2(u_1v_1 + u_2v_2) \quad \cdots \text{(식 2)}$$

**4. 결합: 등식의 완성**

이제 **(식 1)**과 **(식 2)**는 같은 대상을 계산한 것이므로 서로 같아야 합니다.

$$\underbrace{\|\mathbf{u}\|^2 + \|\mathbf{v}\|^2 - 2\|\mathbf{u}\|\|\mathbf{v}\| \cos \theta}_{\text{기하학적 접근 (식 1)}} = \underbrace{\|\mathbf{u}\|^2 + \|\mathbf{v}\|^2 - 2(u_1v_1 + u_2v_2)}_{\text{대수적 접근 (식 2)}}$$

양변에서 공통된 $\|\mathbf{u}\|^2$와 $\|\mathbf{v}\|^2$를 지워버립니다.

$$- 2\|\mathbf{u}\|\|\mathbf{v}\| \cos \theta = - 2(u_1v_1 + u_2v_2)$$

마지막으로 양변을 $-2$로 나눕니다.

$$\|\mathbf{u}\|\|\mathbf{v}\| \cos \theta = u_1v_1 + u_2v_2$$
